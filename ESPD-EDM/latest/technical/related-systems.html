Related Systems

Related Systems

This page provides an overview of EU systems that interact with or are related to the ESPD.

TED (Tenders Electronic Daily)

TED is the online version of the Supplement to the Official Journal of the EU, dedicated to European public procurement. Contract Notices published on TED are referenced from ESPD Request documents.

Portal

ted.europa.eu

Role in ESPD

The ESPD Request references the Contract Notice published on TED via cac:AdditionalDocumentReference. The notice ID follows the format YYYY/S NNN-NNNNNN.

eForms

eForms is the EU notification standard for public procurement procedures. The ESPD-EDM v5.0.0 is aligned with eForms for:

  • Lot identification format (LOT-XXXX, GLO-XXXX)

  • Code lists (shared via EU Vocabularies)

  • Contract Notice linkage

Documentation

SDK repository

Regulation

eForms at EC

e-Certis

e-Certis is the EU information system that helps identify different certificates and evidences requested in procurement procedures across Member States. The ESPD-EDM uses e-Certis as the authoritative source for:

  • Criterion UUIDs

  • Criterion structures (property groups, properties)

  • Criterion type codes

Portal

e-Certis

Role in ESPD

Schematron validation checks that criterion IDs and structures match the canonical definitions from e-Certis.

EU Vocabularies

EU Vocabularies (formerly EuroVoc) provides multilingual controlled vocabularies, authority tables, and code lists used across EU institutions. The ESPD-EDM reuses code lists from EU Vocabularies for:

  • Country codes

  • Currency codes

  • Economic operator size

  • EO role types

  • Exclusion grounds and selection criteria type codes

  • Document reference content types

Portal

EU Vocabularies

ESPD code lists

Interoperability Testbed (ITB)

The Interoperability Testbed is an online tool provided by the European Commission (ISA2 Programme) that enables developers to validate ESPD XML instances against Schematron business rules without any local installation.

ESCO (European Skills, Competences, Qualifications and Occupations)

ESCO provides the classification of professional occupations used in the ESPD for the Occupation code list (criterion "Enrolment in a relevant professional register").

Portal

ESCO Portal

Role in ESPD

Provides occupation codes used as values in cbc:ExpectedCode for suitability criteria.

Joinup

The European Commission’s platform for interoperable digital government solutions. Hosts documentation about ISA2 Programme semantic assets, Core Vocabularies, and the Interoperability Testbed.
