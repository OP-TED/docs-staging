Standards and Specifications

Standards and Specifications

This page provides links to and summaries of the standards and specifications referenced by the ESPD-EDM.

UBL 2.4 (Universal Business Language)

The ESPD-EDM v5.0.0 is based on UBL 2.4, a royalty-free library of standard XML business documents developed by OASIS. The ESPD uses two document types from UBL:

  • QualificationApplicationRequest — for the ESPD Request

  • QualificationApplicationResponse — for the ESPD Response

Specification

OASIS UBL 2.4 Standard

XSD Schemas

UBL 2.4 XSD Runtime Schemas

Technical Committee

OASIS UBL TC

EU Legal basis

Commission Decision 2014/771/EU — identifies UBL 2.1 for referencing in public procurement (UBL 2.4 is backwards compatible)

Genericode 1.0

Genericode is a single model and XML format defined by OASIS for encoding code list information. The ESPD-EDM distributes all code lists as Genericode (.gc) files.

Specification

OASIS Genericode 1.0

ESPD code lists

ESPD-EDM Code Lists on GitHub

ISO Schematron

ISO Schematron (ISO/IEC 19757-3) is a rule-based validation language for making assertions about the presence or absence of patterns in XML documents. The ESPD-EDM uses Schematron to enforce business rules beyond what XSD can validate.

Specification

ISO Schematron

ISO Standard

ISO/IEC 19757-3:2020

ESPD rules

espd-validation-schematron repository

XSLT 3.0

XSLT (Extensible Stylesheet Language Transformations) is used in the ESPD-EDM to compile Schematron into executable XSL and to generate ESPD XML from criterion data.

Specification

W3C XSLT 3.0

Reference implementation

Saxon XSLT Processor

EU Directives and Regulations

The ESPD-EDM implements requirements from the following EU legislation:

Legislation Relevance to ESPD

Directive 2014/24/EU

Public Procurement Directive — Article 59 introduces the ESPD concept. Defines exclusion grounds (Art. 57) and selection criteria (Art. 58).

Directive 2014/25/EU

Utilities Directive — extends public procurement rules to water, energy, transport and postal services sectors.

Regulation (EU) 2016/7

Implementing Regulation establishing the standard form for the European Single Procurement Document.

eForms Regulation

Defines the notification standard for EU public procurement. The ESPD-EDM aligns with eForms for lot management, code lists, and notice references.

Context/Value Association (CVA)

CVA files specify the relationship between XML elements and their associated code lists. Used in the ESPD validation pipeline for code list validation.

Specification

OASIS CVA

Tools

Crane Softwrights CVA to Schematron

ebXML CCTS

The Core Component Technical Specification (ISO/TS 15000-5) provides the data typing foundation for UBL elements (codes and identifiers with their attributes like listID, schemeAgencyID, etc.).

Standard

ISO 15000-5:2014

UBL conformance

UBL Conformance to CCTS
